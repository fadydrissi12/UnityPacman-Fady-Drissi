# Projet Unity Pacman - Fady Drissi

Jeu Pacman realise avec Unity 6 :

- labyrinthe compose de cubes bleus ;
- Pacman represente par une sphere jaune ;
- pellets representes par des cylindres jaunes ;
- quatre ennemis au centre ;
- une porte sur chaque cote ;
- deplacement avec les fleches ou WASD ;
- score affiche dans l'interface et dans la console ;
- passage gauche/droite et haut/bas par teleportation ;
- ecran de defaite `5sert` et bouton `3awed`.

## Installation

1. Installer Unity Hub.
2. Installer ou utiliser Unity 6.6 (`6000.6.5f1`).
3. Cloner le depot :

   ```powershell
   git clone https://github.com/fadydrissi12/UnityPacman-Fady-Drissi.git
   ```

4. Dans Unity Hub, cliquer sur **Add** et selectionner le dossier clone.
4. Ouvrir `Assets/Scenes/Main.unity`.
5. Cliquer sur **Play**.

Le comportement principal se trouve dans `Assets/Scripts/PacmanGame.cs`.
